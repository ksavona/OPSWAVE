## [Unreleased]

### Added

- Public repository documentation and governance baseline.
- Contribution, conduct, and security policies.
- GitHub issue and pull request templates.
- Automated repository hygiene validation.
- Pinned Node.js/pnpm TypeScript modular-monolith workspace.
- Next.js web, Node.js worker, PostgreSQL/Drizzle, domain, AI, and testing foundations.
- Argon2id password and AES-256-GCM AI credential protection wrappers.
- Deterministic fake AI provider and synthetic fixtures.
- Unit, component, route, migration, browser, accessibility, coverage, secret, license, build, and dependency-audit gates.
- Full local/CI validation command and public architecture decision records.
- Apache License 2.0.
- Single-use local owner bootstrap and host-only password recovery commands.
- Argon2id owner policy, generic login responses, opaque digest-only sessions, logout, password rotation, and other-session revocation.
- PostgreSQL-backed login/sensitive-action rate limits with privacy-reduced signals and bounded login events.
- Protected General, Working Time, AI, Prioritisation, and Security settings with optimistic concurrency and accessible capacity previews.
- AES-256-GCM settings-managed provider credential persistence, environment-managed precedence, deterministic fake verification, and redacted audit events.
- Phase 1 PostgreSQL schema/repository contracts plus authenticated browser and accessibility coverage.
- Project and task CRUD, configurable stages, global workflow lanes, deterministic board ordering, derived metrics, task dependencies, and timeline/dependency views.
- Durable deterministic AI intake with owner approval, duplicate surfacing, provenance, retry, 30-day Trash restore, and idempotent purge.
- Deterministic weekly planning previews and trusted task metric/CSV reporting endpoints.
- Regression coverage for the worker run/source identifier boundary, date-only task values, large intake requests, and clean-checkout worker type checking.
- Compact relational Kanban cards with single-click filtering, full-screen rich record editors, drag-and-drop lanes, task deletion, allocated/spent hours, task size, and a single Today lane.
- Project/task dependency editing, grouped searchable/pannable/zoomable Mermaid diagrams, and switchable bar-based Gantt views.
- OpenAI intake enrichment with project matching/proposals, duplicate-work context, full task field extraction, and persistent owner-correction learning memory.
- Exact day/week/month/year/custom-period Gantt windows with allocated-hour task bars, progressive deadline risk styling, full record audit timelines, cross-type blocker filters, and improved orthogonal Mermaid navigation and project coloring.
- Cancelled project stages, collapsed terminal columns, five-card Kanban limits, dependency task ordering, hour-ledger project progress, per-weekday work windows, and persisted Gantt drag scheduling.
- Project-aware intake tags and new-project authorization, editable project-column approval boards, draft task dependency editing, detailed approval history, and deterministic AI task-duration splitting.

Live AI, durable planning automation, report dashboards, and a supported production deployment remain unreleased.
